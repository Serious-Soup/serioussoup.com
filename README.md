# serioussoup.com

Website of Serious Soup, a tiny independent game studio. Served at https://serioussoup.com by GitHub Pages from the `main` branch.

Static files only, no build step: edit, commit, push — the site updates in a minute or two.

Fonts: Bodoni Moda by indestructible type, SIL Open Font License 1.1 (`fonts/OFL.txt`).
