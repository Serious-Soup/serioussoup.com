# Fonts

**In the game** (menus, hints, banners, on-screen text): **Unbounded**, two weights, both here:

- `Unbounded-ExtraBold.ttf`: weight 800, for headings, banners and large text.
- `Unbounded-Medium.ttf`: weight 500, for regular interface text.

Licence: SIL Open Font License 1.1 (`OFL.txt`). Free to use in videos and ads; the font file itself may not be sold.
All weights: https://fonts.google.com/specimen/Unbounded

**Golos Text** is the second brand typeface, for descriptions and small text. It is not part of the game build and
there are no files here; it is free to download (also OFL): https://fonts.google.com/specimen/Golos+Text

The game logo is not set in a font: it is a drawing. Vector files: `02_logos/game_vector/`.
